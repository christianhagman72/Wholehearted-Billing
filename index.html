Firebase Sync

📡 Sync across all devices

  1. Go to console.firebase.google.com
  2. Add project → name it (e.g. we-billing)
  3. Click Web icon (</>) → register app → copy firebaseConfig
  4. Go to Firestore Database → Create → test mode
  5. Open index.html in a text editor, paste your config values at the top
  6. Re-upload all files to GitHub Pages
  7. Open on any device — all data syncs instantly ✅
